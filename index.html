Chrome Extension Mode 🧩

Bring Taveez to every single webpage you visit. The charm hangs from top-right of your viewport, sways with mouse movement, and persists across every tab!

  1. Download or clone this project repository.
  2. Open Chrome and navigate to chrome://extensions.
  3. Enable Developer Mode in the top-right toggle.
  4. Click Load unpacked and select the extension/ directory inside this project.
🔒 100% Private & Safe: Requests minimal permissions (only injects into tabs). Zero tracking, zero network requests!
